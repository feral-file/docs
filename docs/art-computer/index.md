# Art Computer

The Art Computer is a computer that displays digital art. It fetches each work from where the playlist points, and when the work is code it runs the code live. It is the computer inside Feral File Toko. On its own it connects to a TV, projector, or monitor over HDMI.

To set one up, connect power and HDMI. The screen shows each step: put it on Wi-Fi from your phone, then pair it with the Feral File app.

- **Send art to it** from a terminal or a coding agent with [ff-cli](../ff-cli/index.md), or from your own website with [Display on Art Computer](./display.md).
- **Put it on a managed network** (museum, office, campus): [Network Requirements](./network-requirements.md) lists what your IT team needs to allow.
- **Recover it**: [Factory Reset](./factory-reset.md) and [Reinstall FF OS](./reinstall.md).
- **Open it**: [Upgrades](./upgrades.md) for memory and storage, and [Print Your Own Faceplates](./faceplates/index.md).

The hardware specification is on [feralfile.com/ff1](https://feralfile.com/ff1). What is open source, and what the Art Computer does without Feral File, is on [Open source](../open-source.md).
